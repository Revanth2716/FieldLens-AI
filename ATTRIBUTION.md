## What CC-BY-SA-3.0 means for this repository

CC-BY-SA-3.0 is a **share-alike** licence. To comply:

| Item | Handling here |
|---|---|
| Dataset images | **Not redistributed.** `data/` is gitignored; nothing image-bearing is committed. |
| Attribution | Given here, in the README, and on the model-card page of the UI. |
| Test fixtures | **Procedurally generated** synthetic images, not dataset crops, so no dataset content is redistributed via tests. |
| Split manifests | Generated by a committed command from the upstream metadata, not vendored. Upstream file checksums are recorded in [DATASET.md](DATASET.md). |
| Derived metrics and figures | Committed. These are aggregate statistics, not reproductions of the dataset. |
| Trained model weights | **Not committed by default.** Whether share-alike extends to model weights trained on the data is legally unsettled, so the conservative choice is made and documented rather than assumed either way. Weights are reproducible with a single documented command. |

Anyone reusing this work must apply the same attribution and share-alike terms to
the dataset itself.

## Upstream loader note

The upstream Hugging Face loading script declares
`_LICENSE = "CC BY-SA 3.0"` alongside the comment
*"Assuming generic open license, verify if possible."* The licence was therefore
verified independently against the Hugging Face API metadata, which reports the
`license:cc-by-sa-3.0` tag, before relying on it.
